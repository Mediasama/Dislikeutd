# Инструкция по сборке, установке и эмпирическому тестированию GameStretchPro

## 1. Обзор архитектуры плагина
Плагин **Game Stretch Pro (Non-Root)** разработан специально для устройства **Samsung Galaxy A53 5G (SM-A536E)** под управлением **Android 13 / One UI** в среде **AxManager / Shizuku / ADB Shell**.

Файлы плагина:
* `plugin.prop` — Манифест плагина AxManager
* `index.html` — Киберпанк WebUI интерфейс с нейроморфным дизайном
* `main.sh` — Основной скрипт выполнения инновационных non-root методов обхода
* `mon.sh` — Скрипт телеметрии и мониторинга состояния игр и устройства
* `service.sh` — Фоновый сервис отслеживания запуска целевых игр

---

## 2. Сборка архива GameStretchPro.zip
Архив `GameStretchPro.zip` создан без корневой папки внутри:
```bash
zip -r GameStretchPro.zip plugin.prop index.html main.sh mon.sh service.sh
```

## 3. Пошаговая инструкция эмпирического тестирования на Samsung Galaxy A53 5G

### Шаг 1: Подготовка окружения
1. Включите **Отладку по Wi-Fi / ADB Debugging** в настройках разработчика Samsung A53.
2. Запустите **Shizuku** или **AxManager** и убедитесь, что службы имеют права shell.
3. Установите целевые игры:
   * `com.dts.freefiremax` (Free Fire Max)
   * `com.sandboxol.blockymods` (Blocky Mods)

### Шаг 2: Установка плагина
1. Откройте **AxManager**.
2. Перейдите во вкладку **Plugins** -> **Install from file** -> Выберите `GameStretchPro.zip`.
3. Запустите WebUI через кнопку **Open WebUI** или через встроенный браузер AxManager.

### Шаг 3: Поочередное эмпирическое тестирование методов

#### Тестирование Метод 1 (System Compatibility):
1. В WebUI включите только **Метод 1** (остальные выключите).
2. Перейдите во вкладку **Игры**, добавьте `com.dts.freefiremax` или `com.sandboxol.blockymods`.
3. Нажмите **«Применить растяг на весь экран»**.
4. Запустите `com.dts.freefiremax`. Проверьте, исчезли ли боковые черные рамки.

#### Тестирование Метод 2 (One UI Display Scaling):
1. В WebUI включите только **Метод 2**.
2. Нажмите **«Применить растяг на весь экран»**.
3. Запустите `com.sandboxol.blockymods`. Этот метод задействует настройки Samsung Game Booster и `sec_full_screen_apps`.

#### Тестирование Метод 3 (Surface & Cutout Bounds):
1. В WebUI включите **Метод 3**.
2. Нажмите **«Применить растяг на весь экран»**.
3. Метод принудительно устанавливает `cutout-mode never` и `letterbox aspectRatio 2.22` под вытянутый экран 20:9 Samsung A53.

#### Тестирование Метод 4 (Non-Root Aspect Proxy):
1. Включите **Метод 4** или комбинацию всех методов (Метод 1 + Метод 2 + Метод 3 + Метод 4) для максимального эффекта обхода.
2. Проверьте вкладку **Логи**, чтобы убедиться в отсутствии ошибок выполнений shell-команд.

## 4. Результат
После применения выбранного метода игровой движок полностью заполняет всю площадь дисплея Samsung A53 (2400x1080), устраняя letterboxing / pillarboxing, сохраняя при этом системный интерфейс (Launcher, шторку уведомлений) в нетронутом виде.
